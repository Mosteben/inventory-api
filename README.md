# Inventory Management System API

## Requirements

- PHP 8.2+
- Composer
- MySQL
- Apache (XAMPP)

## Installation

Clone Repository

```bash
git clone https://github.com/Mosteben/inventory-api.git
```

Install Packages

```bash
composer install
```

Copy Environment

```bash
cp .env.example .env
```

Import Database

database/inventory.sql

Run Apache & MySQL

API URL

http://localhost/inventory-api/public/index.php
